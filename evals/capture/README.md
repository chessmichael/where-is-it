# Capture eval

Does the app's agent turn what people say into the right records, and answer "where is it?" correctly?
Each case runs the real conversation and tidy-up agents against a throwaway house database, with a
simulated person answering any questions, then checks the database and the spoken replies.

- **Cases:** `cases.md` (readable) / `cases.json` (run) — both generated by `build_cases.py`.
- **Suites:** `suites.json` (from `make_suites.py`): **capability** cases still tell versions apart;
  **regression** cases every version passes.
- **Results:** `.claude/hillclimb/capture/<variant>/` — open `cases.html` there for a readable
  case-by-case view; each case links to an inspector page for its final database.
- **Ledger:** `ledger.jsonl` — append-only record of every approval, run, re-run and suite change
  (who, when, which code, which harness, scores). Verified by `verify-ledger.mjs` and the pre-commit hook.

## Everyday commands

```bash
npm run eval:selftest                                              # free: grader passes right answers, fails wrong ones
npm run eval:capture -- --variant v4 --suite capability --reps 3   # an experiment: the discriminating cases, 3 repeats
npm run eval:capture -- --variant v4 --suite regression            # before deploying: nothing that worked is broken
npm run eval:capture -- --variant v4                               # everything
npm run inspect -- --eval v4 D06                                   # look at one case's final database
```

- Re-running the same command **resumes**: only missing (case, repeat) pairs run.
- `--approve-harness` is needed (once) after the grader or harness changes; it's recorded in the ledger.
- `--code <commit>` runs an earlier version's agent code under today's grader (to keep comparisons fair
  after a grader fix); `--rerun <ids|set:X|all> --reason "…"` supersedes existing rows (archived, logged).
- Your OpenAI project allows ~1M tokens/minute: run one variant at a time.
